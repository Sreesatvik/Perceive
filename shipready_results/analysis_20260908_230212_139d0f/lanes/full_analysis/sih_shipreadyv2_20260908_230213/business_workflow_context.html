Workflow 1

Privacy and redaction orchestration

What this workflow does

Browser page inspection turns sensitive DOM fields into semantic tokens and a redacted canvas payload for the privacy demo.

Purpose

inspect a checkout-style page and convert sensitive fields into safe representations

What it produces

DOM elements and outgoing redaction payload

Who relies on it

browser user / transport consumer

Why this workflow matters

  • prevents raw sensitive values from appearing in the outgoing payload
  • produces a sanitized canvas image and structured DOM summary
  • preserves locally resolvable semantic tokens for the same sensitive values
